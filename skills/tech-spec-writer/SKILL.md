# Tech Spec Writer

## Description

技术方案生成助手 - 协助编写自动驾驶项目的技术方案文档。

## When to Use

- 新项目立项
- 技术选型决策
- 方案评审准备
- 技术汇报材料

## How to Use

1. 描述项目背景和目标
2. 提供约束条件（时间/资源/技术栈）
3. 获取方案框架或完整文档

## Templates

### 模板1：传感器选型方案
```markdown
# XX传感器选型技术方案

## 1. 需求分析
- 功能需求
- 性能需求
- 环境需求

## 2. 候选方案
| 方案 | 优势 | 劣势 | 成本 |
|------|------|------|------|
| A | ... | ... | ... |
| B | ... | ... | ... |

## 3. 推荐方案
- 选型：...
- 理由：...

## 4. 实施计划
- Phase 1: ...
- Phase 2: ...

## 5. 风险评估
```

### 模板2：算法优化方案
```markdown
# XX算法优化技术方案

## 1. 现状分析
## 2. 问题定义
## 3. 优化目标
## 4. 技术路线
## 5. 验证方案
## 6. 资源需求
```

## Examples

### 例1：生成相机选型方案
```
需求：
- 前视主相机，120度FOV
- 夜间可用，支持HDR
- 车规级，-40~85℃
- 预算 < 2000元/颗

请生成选型方案。
```

## Notes

- 方案必须有数据支撑
- 风险评估不可省略
- 考虑供应链因素
- 预留回退方案
