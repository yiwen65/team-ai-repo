# 数据闭环参考

## 数据闭环流程

```
[数据采集]
  ├── 触发条件：脱离、难例、场景覆盖盲区
  ├── 采集内容：传感器原始数据 + 标注 + 日志 + 地图
  └── 隐私合规：人脸/车牌脱敏
        │
        ▼
[数据标注]
  ├── 自动标注（预标注 + 模型辅助）
  ├── 人工审核（质检 + 边界case）
  └── 验收标准：mAP > 95% 自动标注质量
        │
        ▼
[模型训练]
  ├── 数据增强（时序、天气、光照）
  ├── 增量训练（避免灾难性遗忘）
  └── 验证：离线测试 + A/B 对比
        │
        ▼
[模型验证]
  ├── SIL 测试：场景库回归
  ├── HIL 测试：硬件兼容性
  └── 实车测试：封闭场地 + 开放道路
        │
        ▼
[OTA 发布]
  ├── 灰度发布：1% → 10% → 100%
  ├── 回滚策略：版本号 + 校验和
  └── 监控：脱离率、误触发率、性能指标
```

## 数据采集触发策略

| 触发条件 | 采集内容 | 优先级 |
|---------|---------|--------|
| 安全员接管 | 前后 30s 全传感器数据 | P0 |
| AEB 误触发 | 前后 10s 数据 | P0 |
| 感知漏检 | 目标消失前后 5s | P1 |
| 规划无解 | 场景 + 地图片段 | P1 |
| 场景覆盖盲区 | 常规数据 | P2 |
| 模型置信度低 | 单帧 + 上下文 | P2 |

## 标注规范

| 类型 | 标注内容 | 精度要求 | 质检 |
|------|---------|---------|------|
| 2D 检测 | 边界框 + 类别 | IoU > 0.9 | 抽查 5% |
| 3D 检测 | 3D 框 + 朝向 | 位置 < 0.1m | 抽查 10% |
| 语义分割 | 逐像素类别 | 边缘 < 2px | 全量质检 |
| 车道线 | 关键点 + 类型 | 位置 < 0.05m | 抽查 5% |
| 轨迹预测 | 未来 3s 位置 | 位置 < 0.5m | 自动验证 |

## OTA 流程

```
版本准备
  ├── 模型加密 + 签名
  ├── 差分包生成（减少流量）
  └── 兼容性检查（硬件/软件版本）
        │
        ▼
云端发布
  ├── 灰度：内部车 → 测试车队 → 用户（1% → 10% → 100%）
  ├── 每阶段监控：脱离率、误触发率、系统稳定性
  └── 异常自动回滚（阈值：脱离率 +20%）
        │
        ▼
车端更新
  ├── 下载：后台下载，不影响驾驶
  ├── 安装：泊车时安装，双分区（A/B 分区）
  └── 验证：启动自检，失败回滚到旧版本
```

## 数据合规

| 法规 | 要求 | 实施 |
|------|------|------|
| GDPR | 用户同意、数据可删除 | 采集前弹窗同意 |
| 中国个保法 | 敏感信息脱敏 | 人脸/车牌模糊化 |
| 网络安全法 | 数据不出境 | 国内数据中心存储 |
