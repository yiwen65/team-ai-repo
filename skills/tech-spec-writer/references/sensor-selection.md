# 传感器选型参考

## 相机选型

| 参数 | 前视主相机 | 环视相机 | 后视/侧视 |
|------|-----------|---------|----------|
| 分辨率 | 8MP (3840x2160) | 2MP (1920x1080) | 2MP (1920x1080) |
| FOV | 120° H / 60° V | 190° H / 120° V (鱼眼) | 100° H / 50° V |
| 帧率 | 30fps | 30fps | 30fps |
| HDR | > 120dB | > 100dB | > 80dB |
| 动态范围 | 支持 | 支持 | 可选 |
| LED 闪烁抑制 | 必须 | 可选 | 可选 |
| 工作温度 | -40 ~ 85°C | -40 ~ 85°C | -40 ~ 85°C |
| 防护等级 | IP67 | IP67 | IP67 |
| 典型价格 | $80-150 | $30-50 | $30-50 |

**选型决策树**：
```
是否需要夜间识别？
  否 → 普通 HDR 相机
  是 → 是否需要高动态范围（隧道出入口）？
    否 → HDR 相机
    是 → 支持 LED 闪烁抑制 + 高动态范围
```

## 激光雷达选型

| 类型 | 探测距离 | 角分辨率 | 价格 | 适用 |
|------|---------|---------|------|------|
| 机械旋转 (128线) | 200m@10% | 0.1°x0.2° | $8K-15K | Robotaxi |
| 半固态 (MEMS) | 150m@10% | 0.2°x0.2° | $3K-6K | 高端乘用车 |
| 固态 (Flash) | 50m@10% | 0.5°x0.5° | $500-1K | 泊车/补盲 |
| 4D 成像雷达 | 300m | 1°x1° | $300-800 | 高速/雨雾 |

**关键参数**：
- 探测距离 @10% 反射率（而非 @90%，更真实）
- 点频（points/sec）：影响小目标检测
- 视场角：水平 120°+ 才能覆盖路口
- 帧率：10Hz 最低，20Hz 更佳（高速场景）
