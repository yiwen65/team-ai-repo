# 算法选型参考

## 感知算法选型

| 算法 | 模态 | mAP (nuScenes) | 延迟 (Orin) | 显存 | 适用 |
|------|------|---------------|------------|------|------|
| BEVFusion | C+L | 70.2 | 80ms | 12GB | 城市 NOA |
| CenterPoint | L | 60.3 | 50ms | 6GB | 高速 |
| BEVDet | C | 31.2 | 60ms | 8GB | 低成本 |
| DETR3D | C | 41.2 | 70ms | 10GB | 研究 |
| PETR | C | 44.1 | 65ms | 10GB | 研究 |
| TransFusion | L+C | 68.9 | 75ms | 11GB | 城市 NOA |

**选型决策矩阵**：

| 约束 | 推荐方案 |
|------|---------|
| 算力 > 200 TOPS + 城市 | BEVFusion / TransFusion |
| 算力 50-100 TOPS + 高速 | CenterPoint + 相机后融合 |
| 算力 < 30 TOPS + 高速 | BEVDet / YOLOv8-3D |
| 纯视觉 + 极低成本 | BEVDet-Lite / LSS |

## 规划算法选型

| 算法 | 场景 | 优势 | 劣势 |
|------|------|------|------|
| EM Planner (Apollo) | 结构化道路 | 分层解耦、成熟 | 复杂场景易无解 |
| Lattice Planner | 高速/快速路 | 平滑、可控 | 场景泛化有限 |
| OpenSpace | 泊车/窄路 | 非结构化 | 计算量大 |
| Optimization (MPC) | 通用 | 多约束最优 | 实时性挑战 |
| 端到端 (UniAD) | 通用 | 联合优化 | 可解释性差 |

## 控制算法选型

| 算法 | 横向/纵向 | 延迟要求 | 计算量 | 适用 |
|------|----------|---------|--------|------|
| MPC | 横+纵 | < 50ms | 高 | 高速、复杂场景 |
| Stanley | 横 | < 20ms | 低 | 中速 |
| Pure Pursuit | 横 | < 20ms | 低 | 低速/泊车 |
| PID | 纵 | < 10ms | 极低 | 跟车 |
| LQR | 横 | < 20ms | 中 | 平滑参考线 |
