# Code Reviewer

## Description

代码审查助手 - 对自动驾驶相关代码进行质量审查和优化建议。

## When to Use

- 提交代码前自检
- 团队代码审查
- 学习优秀代码实践
- 重构旧代码时

## How to Use

1. 粘贴代码片段或文件路径
2. 说明审查重点（性能/安全/可读性/架构）
3. 获取审查报告

## Review Dimensions

- **安全性**: 内存安全、越界检查、异常处理
- **性能**: 算法复杂度、缓存友好、并行化
- **可读性**: 命名规范、注释质量、函数长度
- **架构**: 模块化、耦合度、可测试性
- **ROS规范**: 节点设计、话题命名、参数配置

## Output Format

```markdown
# 代码审查报告

## 概要
- 风险等级：高/中/低
- 主要问题数：X
- 建议优化数：X

## 严重问题
1. [问题描述]
   - 位置：行号
   - 风险：...
   - 建议：...

## 优化建议
1. [建议]
   - 当前：...
   - 建议：...

## 正面评价
- 代码亮点...
```

## Notes

- 自动驾驶代码特别注意实时性要求
- 传感器数据处理注意资源释放
- 多线程代码注意竞态条件
