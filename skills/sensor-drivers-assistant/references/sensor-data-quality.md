# 传感器数据质量验证

一句话简介：Apollo-Lite 传感器数据质量直接影响感知、定位和规划的安全性，需对点云密度、图像清晰度、目标稳定性、时间戳一致性进行持续监控和量化评估。

## 核心概念/原理

数据质量指标体系：
- **完整性**：数据帧是否连续、无丢帧
- **准确性**：测量值与真实值的偏差（需标定场验证）
- **一致性**：多传感器间时间戳对齐、空间对齐
- **时效性**：数据采集到发布的端到端延迟

## Apollo-Lite 中的实现位置

- 数据验证工具：`modules/tools/whl-tool/`、`modules/tools/whl-toolbox/`
- cyber_recorder：`cyber/tools/cyber_recorder/`
- 日志分析：`modules/tools/whl-debug/`

## 质量评估方法

| 传感器 | 关键指标 | 合格阈值 | 验证方法 |
|--------|---------|---------|---------|
| LiDAR | 点云密度 | > 1000 pts/° | 统计每帧点数和角度覆盖 |
| Camera | 图像清晰度 | MTF > 0.5 | 棋盘格/边缘锐度检测 |
| Radar | 目标稳定性 | ID 保持率 > 90% | 跟踪器连续性统计 |
| GNSS | RTK 固定率 | > 95% | `GnssStatus` 解算状态统计 |
| IMU | 噪声水平 | 角速度 std < 0.01°/s | Allan 方差分析 |

## 常见问题与排查

- **丢帧**：检查驱动 buffer 大小和消费线程
- **数据抖动**：检查时间同步和触发信号质量
- **异常值**：设置合理的门限，结合多传感器交叉验证

## 与其他模块的接口

- **monitor**：数据质量异常上报 Monitor 告警
- **guardian**：严重数据质量故障触发安全降级
- **perception**：数据质量差时感知模块可降低置信度或切换备用传感器
