# Calibration Assistant

## Description

标定助手 - 协助完成相机、激光雷达、IMU 等传感器的标定工作。

## When to Use

- 需要分析标定数据质量时
- 需要生成标定报告时
- 需要排查标定异常时
- 需要优化标定参数时

## How to Use

1. 提供标定数据（内参、外参、重投影误差等）
2. 描述当前问题或目标
3. 获取分析结果和建议

## Examples

### 例1：检查标定质量
```
标定数据：
- 相机内参：fx=1000, fy=1000, cx=640, cy=360
- 重投影误差：mean=2.5px, max=8.3px
- 标定板角点数量：48/50

请分析标定质量，并给出改进建议。
```

### 例2：生成标定报告
```
请根据以下数据生成标定报告：
[粘贴标定数据]
```

## Output Format

```markdown
# 标定分析报告

## 1. 数据概览
## 2. 质量评估
## 3. 问题诊断
## 4. 改进建议
## 5. 下一步行动
```

## Notes

- 重投影误差 < 1px 为优秀，1-3px 为良好，> 3px 需优化
- 标定板角点检测率应 > 90%
- 注意检查畸变参数的合理性
