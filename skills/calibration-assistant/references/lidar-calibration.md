# 激光雷达标定参考

## 雷达类型与标定特点

| 类型 | 代表型号 | 标定重点 | 内参项 |
|------|---------|---------|--------|
| 机械旋转 | Velodyne HDL-64E, Ouster OS1 | 旋转轴垂直度、角分辨率均匀性 | 每线俯仰角、方位角偏差 |
| 半固态(MEMS) | Livox Horizon, RoboSense M1 | 扫描非线性、FOV边界畸变 | 扫描镜角度映射 |
| 固态(Flash) | IbeoNEXT, Continental | 像素级内参、深度校准 | 像素-角度映射、距离偏差 |

## 激光雷达内参标定

**机械旋转雷达**：
- 每线的垂直角偏差（标称 0.4°，实际可能有 ±0.05° 偏差）
- 水平角分辨率不均匀（由电机转速波动引起）
- 距离系统误差（由时间测量电路延迟引起）

**标定方法**：
1. 将雷达置于开阔场地，扫描平面墙
2. 提取墙面点云，拟合平面
3. 计算每线点云到拟合平面的距离偏差
4. 优化每线的垂直角修正值和距离修正值

## 激光雷达-相机联合标定

**关键步骤**：
1. 同步采集标定板图像和点云（trigger 或软同步）
2. 图像中提取标定板角点（2D）
3. 点云中提取标定板平面和边缘（3D）
4. 最小化重投影误差：argmin Σ ||proj(K[R|t]X_lidar) - x_image||²

**精度标准**：
- 标定板角点重投影误差 < 5px
- 10m 处目标边缘对齐误差 < 3px
- 50m 处目标位置偏差 < 0.5m
