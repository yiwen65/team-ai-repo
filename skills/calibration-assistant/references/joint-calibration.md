# 联合标定参考

## 联合优化问题定义

多传感器联合标定的目标是最小化所有传感器观测的一致性误差：

```
minimize Σ_ij ||f_i(X; θ_i) - f_j(X; θ_j)||² + λ_reg * ||θ - θ_prior||²
```

其中：
- `f_i`: 传感器 i 的观测模型
- `θ_i`: 传感器 i 的标定参数（内参+外参）
- `X`: 场景特征点（标定板角点、自然特征）
- `λ_reg`: 先验正则化权重（防止过拟合）

## 典型传感器拓扑

```
                    [GNSS/RTK]
                         |
                    [IMU] (车辆坐标系原点)
                   /    \
            [左相机]  [右相机]  [前相机]
               |        |        |
            [左雷达]  [右雷达]  [前雷达]
               \        |        /
                  [激光雷达主]
```

**约束设计**：
- IMU → 车辆：固定安装，几乎无自由度
- 相机 → IMU：6DOF，需时延标定
- 激光雷达 → 相机：6DOF，需时间同步
- 毫米波 → 相机：6DOF，角度精度有限

## 联合标定工具链

| 工具 | 功能 | 适用场景 |
|------|------|---------|
| Kalibr | 相机-IMU 联合标定 | 视觉-惯性融合 |
| LiDAR-Camera-Calibration | 激光雷达-相机 | 单对传感器 |
| Autoware 标定工具 | 多传感器联合 | ROS2 系统 |
| 自定义优化 | 全传感器联合 | 量产平台 |

## 时间同步标定

**时间偏移影响量化**：
- 车辆 80km/h (22.2m/s) 时，1ms 时间偏移 = 2.2cm 位置偏差
- 快速转向场景（0.3rad/s），1ms = 0.3mrad 航向偏差

**标定方法**：
1. 运动场景采集（加速、减速、转向）
2. 利用运动约束（IMU 积分 vs 视觉/点云里程计）
3. 优化时间偏移 τ：min ||T_imu(t) - T_cam(t + τ)||
