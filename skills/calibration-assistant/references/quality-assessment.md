# 标定质量评估参考

## 验证场景设计

| 场景 | 验证目的 | 通过标准 |
|------|---------|---------|
| 静态标定板 | 基础精度 | 重投影 < 3px @ 5m |
| 多距离目标 | 深度一致性 | 位置偏差 < 1% 距离 |
| 动态环岛 | 旋转一致性 | 目标跨传感器跟踪 ID 不切换 |
| 夜间场景 | 低光稳定性 | 与日间偏差 < 20% |
| 高温环境 | 温度稳定性 | 重投影 < 5px @ 50°C |

```markdown
## 结论
- [ ] 通过量产标定标准
- [ ] 需重标定（原因：___）
```

## 标定参数版本管理

**命名规范**：
```
<vehicle_model>_<sensor_config>_<calib_date>_<version>.yaml
例：SUV_A_v1.2_20260522_v3.yaml
```

**字段要求**：
- calib_version: 3
- vehicle_model: "SUV_A"
- sensor_config: "6cam_2lidar_5radar"
- calib_date: "2026-05-22"
- operator: "张三"
- temperature: 25.0
- validation_result: "PASS"
- hash: SHA256 校验值
