# 在线标定参考

## 在线标定触发策略

| 触发条件 | 检测方法 | 阈值 |
|---------|---------|------|
| 时间 | 距上次标定 > 30 天 | 固定 |
| 里程 | 行驶 > 5000km | 固定 |
| 温度 | 环境温度变化 > 40°C | 传感器反馈 |
| 振动 |  detected 碰撞/剧烈颠簸 | IMU 冲击检测 |
| 漂移 | 在线监控指标超阈值 | 见下表 |

## 在线漂移监控指标

| 指标 | 计算方法 | 警告阈值 | 严重阈值 |
|------|---------|---------|---------|
| 相机-激光雷达重投影误差 | 边缘点投影偏差 | > 5px | > 10px |
| 环视重叠区匹配误差 | SIFT/ORB 特征匹配 | > 3px | > 5px |
| 车道线平行度偏差 | 车道线拟合斜率 | > 0.5° | > 1.0° |
| 灯杆垂直度偏差 | 场景垂直特征检测 | > 1.0° | > 2.0° |
| IMU-视觉姿态差异 | VIO 漂移量 | > 0.5% | > 1.0% |

## 无标定板自标定方法

**场景特征选择标准**：
- 垂直特征：灯杆、建筑边角、交通标志杆（俯仰角约束）
- 水平特征：车道线、路沿（横滚角约束）
- 平面特征：路面、墙面（高度约束）
- 要求：特征在 50m 内分布均匀，高度 > 2m

**优化框架**：
```
while driving:
    检测场景特征（车道线、灯杆、建筑边角）
    累积多帧观测
    if 特征数量 > threshold 且 分布良好:
        优化外参 [R|t] 最小化特征不一致性
        if 协方差收敛:
            输出标定修正量
            验证：应用修正后观察指标是否改善
```

## 温度补偿模型

标定参数随温度变化模型（多项式拟合）：
```
Δθ(T) = a₁(T - T₀) + a₂(T - T₀)²
```

- T₀: 标定时的环境温度
- a₁: 一阶温度系数（支架热胀冷缩）
- a₂: 二阶系数（非线性材料特性）

**典型值**（铝制支架）：
- 平移漂移：~0.3mm/°C
- 旋转漂移：~0.002°/°C
