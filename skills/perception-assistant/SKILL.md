# Perception Assistant

## Description

感知助手 - 协助自动驾驶感知模块的开发、调试和优化。

## When to Use

- 多传感器数据融合分析
- 障碍物检测和跟踪问题排查
- 感知算法参数调优
- 传感器标定验证
- 数据集质量检查

## How to Use

1. 描述传感器配置（相机、激光雷达、毫米波雷达）
2. 提供检测数据或问题描述
3. 获取分析和建议

## Examples

### 例1：多传感器融合分析
```
传感器配置：
- 前视相机：1920x1080，FOV 120°
- 激光雷达：64线，探测距离 200m
- 毫米波雷达：前向，探测距离 150m

问题：
- 相机检测到行人，但激光雷达未检出
- 距离：35m，光照：黄昏

请分析原因并给出建议。
```

### 例2：障碍物跟踪优化
```
跟踪数据：
- 目标：前方车辆
- 跟踪时长：5s后丢失
- 速度：60km/h
- 遮挡情况：轻微遮挡

请分析跟踪丢失原因。
```

## Output Format

```markdown
# 感知分析报告

## 1. 传感器配置概览
## 2. 问题分析
## 3. 根因定位
## 4. 解决方案
## 5. 参数调优建议
## 6. 验证方法
```

## Notes

- 注意传感器时间同步问题
- 关注不同传感器的盲区互补
- 考虑光照、天气对视觉的影响
- 检查激光雷达反射率阈值设置
