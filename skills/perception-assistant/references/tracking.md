# 跟踪与时序参考

## 多目标跟踪（MOT）方案

| 方案 | 关联方式 | 优势 | 劣势 |
|-----|---------|------|------|
| ByteTrack | 检测框 + 卡尔曼 | 简单高效，依赖检测质量 | 遮挡场景易 ID 切换 |
| StrongSORT | DeepSORT 改进 | 外观特征 + 运动模型 | 计算量大 |
| OC-SORT | 观测-centric | 遮挡恢复能力强 | 超参数敏感 |
| QD-3DT | 3D 跟踪 | 利用 3D 几何信息 | 需要 3D 检测结果 |

## 时序对齐关键参数

```python
# ROS2 消息同步典型配置
from message_filters import Subscriber, ApproximateTimeSynchronizer

sync = ApproximateTimeSynchronizer(
    [cam_sub, lidar_sub, radar_sub],
    queue_size=10,
    slop=0.05  # 50ms 容忍窗口，高速场景建议 <= 30ms
)
```

**跟踪丢失常见根因**：
1. **时间同步偏移** → 传感器数据不同步导致关联失败
2. **检测帧率不足** → 高速目标跨帧位移 > 关联阈值
3. **遮挡恢复延迟** → 卡尔曼预测在遮挡期间发散
4. **ID 切换** → 相似目标（同型号车辆）外观特征区分度不足

## 航迹关联阈值设定

| 场景 | 距离阈值 (m) | IoU 阈值 | 说明 |
|------|-------------|---------|------|
| 城市道路 (< 40km/h) | 2.0 | 0.3 | 目标密集，允许更大阈值 |
| 快速路 (40-80km/h) | 1.5 | 0.4 | 平衡精度与召回 |
| 高速 (> 80km/h) | 1.0 | 0.5 | 严格匹配，减少误关联 |
