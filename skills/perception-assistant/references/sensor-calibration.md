# 传感器标定参考

## 标定类型与精度要求

| 标定类型 | 典型精度 | 验证方法 | 漂移检测周期 |
|---------|---------|---------|-------------|
| 相机内参 | 重投影误差 < 0.3px | 棋盘格/ArUco 标定板 | 每季度 |
| 相机-相机（环视） | 相邻相机重叠区特征点误差 < 2px | 场景特征匹配 | 每月 |
| 相机-激光雷达 | 重投影误差 < 5px（边缘点） | 标定板角点/边缘对齐 | 每周（在线） |
| 激光雷达-IMU | 时间偏移 < 5ms | 运动场景同步验证 | 每次启动 |
| 毫米波雷达-相机 | 角度误差 < 0.5° | 目标关联验证 | 每月 |

## 在线标定（Online Calibration）

**触发条件**：
- 车辆行驶里程 > 1000km 未执行静态标定
- 温度变化 > 30°C（热胀冷缩导致支架微移）
- 发生碰撞/颠簸/维修后

**常用方法**：
- 基于场景特征的相机外参自标定（利用车道线、灯杆等垂直/水平特征）
- 激光雷达-相机联合优化（最小化投影边缘残差）
- 基于轮速计/IMU 的运动约束标定

## 标定验证 Checklist

- [ ] 检查各传感器 topic 的 timestamp 是否单调递增
- [ ] 验证标定结果在 5m/20m/50m/100m 处的投影精度
- [ ] 检查车辆坐标系（后轴中心/质心/IMU中心）定义一致性
- [ ] 确认标定参数加载路径和版本管理（避免加载旧版参数）
