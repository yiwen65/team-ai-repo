# 数据质量参考

## 数据集分布检查清单

- [ ] 场景覆盖：城市道路、高速、隧道、夜间、雨天、雪天
- [ ] 目标类别分布：车辆、行人、骑车人、锥桶、动物、异形车
- [ ] 距离分布：0-10m、10-30m、30-50m、50-100m、>100m
- [ ] 尺寸分布：小目标（< 32px）、中目标、大目标占比
- [ ] 遮挡程度：无遮挡、部分遮挡、重度遮挡

## 标注质量检查

| 检查项 | 方法 | 合格标准 |
|-------|------|---------|
| 框精度 | 抽查 5% 样本可视化 | 边缘贴合目标，无漏标 |
| 类别一致性 | 同一目标跨帧类别一致性 | 类别切换率 < 0.1% |
| 3D 框精度 | 投影到图像验证 | 重投影 IoU > 0.85 |
| 点云分割 | 检查边界点归属 | 边缘 10cm 内无误分 |

## 长尾问题诊断

**现象**：某类目标召回率显著低于其他类别

**排查步骤**：
1. 统计训练集中该类样本数（是否 < 1000）
2. 检查该类标注质量（是否有系统性偏差）
3. 分析误检/漏检场景（光照、角度、遮挡模式）
4. 评估该类与其他类的特征混淆度

**解决方案优先级**：
1. 补充真实数据（最有效）
2. 数据增强（复制粘贴、GAN 生成）
3. 类别权重调整 / Focal Loss
4. 专用子网络（Cascade RCNN 分支）
