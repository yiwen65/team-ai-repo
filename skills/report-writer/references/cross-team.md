# 跨团队沟通参考

```markdown
# [通知] 感知模块输出接口变更 v2.3 → v2.4

## 变更原因
支持新类别"异形车辆"，满足城市 NOA 需求。

## 变更内容
| 字段 | 旧版本 (v2.3) | 新版本 (v2.4) | 影响 |
|------|-------------|-------------|------|
| object_class | enum {CAR, PED, ...} | enum {CAR, PED, ..., ABNORMAL_VEHICLE} | 规划模块需处理新类别 |
| confidence | float32 | float32 (范围不变) | 无影响 |
| + shape_type | 无 | enum {BOX, CYLINDER, POLYGON} | 规划碰撞检测需适配 |

## 影响范围
- ✅ 规划模块：需处理 ABNORMAL_VEHICLE 类别
- ✅ 仿真模块：需生成异形车辆场景
- ⬜ HMI 模块：需显示新类别图标（已通知）
```

```markdown

## 依赖清单
| 依赖项 | 提供方 | 截止时间 | 状态 | 阻塞风险 |
|--------|--------|---------|------|---------|

## 阻塞项处理
**TensorRT 8.6.2 延迟风险**
- 原因：新特性 `IPluginV2DynamicExt` 变更，plugin 需重写
- 缓解：已安排平台团队 2 人支援，并行开发
- 回退：如延迟 > 1 周，使用 TensorRT 8.5 + 功能降级

**标定漂移风险**
- 原因：温度变化导致 20m 处误差超阈值
- 缓解：引入在线补偿，已验证精度恢复
- 回退：如补偿效果不佳，增加静态重标定频率

## 下一步
- 每日站会对齐依赖状态
- 风险升级：若任何依赖延迟 > 3 天，自动升级至 TL 层面
```

## 沟通技巧

- **结构化信息**：变更通知必须有"影响范围 + 时间线 + 联系人"
- **前置通知**：接口变更至少提前 2 周通知，不要突然改
- **提供迁移支持**：不要只说"你改一下"，要提供示例代码/文档
- **阻塞要升级**：依赖延迟不要等，提前 3 天升级
- **向下兼容优先**：能不 break 就不 break，生态友好
