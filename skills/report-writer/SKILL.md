# Report Writer

## Description

汇报材料生成助手 - 协助编写自动驾驶项目的技术汇报、汇报PPT和展示材料。

## When to Use

- 项目阶段汇报
- 技术方案汇报
- 问题分析汇报
- 成果展示材料
- 会议纪要整理

## How to Use

1. 描述汇报对象（领导/客户/团队）
2. 提供核心内容和数据
3. 获取结构化汇报材料

## Examples

### 例1：项目进度汇报
```
汇报对象：部门领导
项目：前视感知算法优化
时间：2026年Q2

进展：
- 完成模型训练，mAP提升5%
- 完成实车测试，问题收敛
- 待完成：量产适配

请生成汇报PPT大纲。
```

### 例2：技术方案汇报
```
汇报对象：技术委员会
主题：多传感器融合方案

要点：
- 当前问题：单传感器漏检
- 方案：相机+激光雷达融合
- 预期效果：漏检率降低80%
- 资源需求：2人月

请生成汇报材料。
```

## Output Format

```markdown
# 汇报材料

## 1. 汇报概览
- 对象
- 目的
- 时间

## 2. 核心内容
- 背景
- 进展/方案
- 数据支撑

## 3. 关键结论
- 成果
- 风险
- 下一步

## 4. Q&A准备
- 可能的问题
- 预设回答
```

## Notes

- 汇报要结论先行
- 数据要可视化
- 控制汇报时长
- 准备Q&A
