# Planning Control Assistant

## Description

规划控制助手 - 协助自动驾驶路径规划、轨迹生成和控制算法优化。

## When to Use

- 路径规划算法选择和参数调优
- 轨迹生成问题分析
- 控制算法（横向/纵向）调试
- 规划控制联合优化
- 场景分析和策略制定

## How to Use

1. 描述场景（城市道路、高速、泊车等）
2. 提供当前问题或目标
3. 获取技术分析和优化建议

## Examples

### 例1：泊车路径规划
```
场景：垂直泊车
- 车位尺寸：2.5m x 5.5m
- 车辆尺寸：1.8m x 4.8m
- 当前位置：车位前方2m，偏移0.3m

请生成泊车路径并分析可行性。
```

### 例2：弯道控制优化
```
问题：高速弯道行驶，车辆出现超调
- 弯道半径：150m
- 车速：80km/h
- 横向误差：max 0.8m

请分析控制参数并给出优化建议。
```

## Output Format

```markdown
# 规划控制分析报告

## 1. 场景分析
## 2. 约束条件
## 3. 技术方案
## 4. 参数建议
## 5. 仿真验证
## 6. 风险评估
```

## Notes

- 规划算法注意实时性要求
- 控制算法注意稳定性边界
- 轨迹平滑性影响乘坐舒适性
- 考虑车辆动力学约束
