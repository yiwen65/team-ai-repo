# 全局规划参考

## 地图与拓扑规划

**输入**：高精度地图（Lanelet2/OpenDRIVE）、起点终点、交通规则
**输出**：车道级全局路径（waypoint sequence）

## 算法对比

| 算法 | 适用场景 | 优势 | 劣势 |
|------|---------|------|------|
| A* | 简单网格/拓扑 | 最优、快 | 高维空间膨胀 |
| Dijkstra | 带权图 | 保证最优 | 慢 |
| Hybrid A* | 车辆运动学 | 考虑非完整性 | 非最优 |
| RRT* | 高维/复杂约束 | 概率完备 | 收敛慢 |
| Lattice | 结构化道路 | 平滑、可控 | 需要参考线 |

## 地图精度要求

| 指标 | 要求 | 说明 |
|------|------|------|
| 车道线精度 | < 10cm | 直接影响参考线质量 |
| 拓扑连通性 | 100% | 断链导致规划失败 |
| 红绿灯位置 | < 1m | 停止线定位准确 |
| 路口复杂度 | 完整标注 | 转向、合流、分流 |

## 常见问题

| 现象 | 根因 | 解决方案 |
|------|------|---------|
| 全局路径绕远 | 地图拓扑权重不合理 | 调整通行效率权重 |
| 进入错误车道 | 车道连接关系错误 | 更新地图拓扑 |
| 规划突然跳变 | 全局规划重算 + 平滑不足 | 增加路径缓存和平滑过渡 |
