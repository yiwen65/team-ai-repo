# 横向控制参考

## 算法对比

| 算法 | 原理 | 优势 | 劣势 | 适用场景 |
|------|------|------|------|---------|
| Pure Pursuit | 几何跟踪 | 简单、鲁棒 | 高速 cutting corner | 低速、泊车 |
| Stanley | 横向误差 + 航向误差 | 收敛快 | 高速震荡 | 中速 |
| MPC | 模型预测优化 | 多约束、最优 | 计算量大 | 高速、复杂场景 |
| LQR | 线性二次调节 | 理论完备 | 线性假设 | 参考轨迹平滑时 |

## MPC 横向控制关键参数

```python
mpc_params = {
    "N": 20,           # 预测步数
    "dt": 0.1,         # 采样时间 (s)
    "Q": [1.0, 0.0, 0.1],  # 状态权重 [横向误差, 航向误差, 曲率]
    "R": [0.1],        # 控制权重 [前轮转角]
    "constraints": {
        "delta_max": 0.35,      # 最大舵角 (rad)
        "delta_rate_max": 0.2,  # 最大舵角速度 (rad/s)
        "ay_max": 2.5           # 最大横向加速度 (m/s²)
    }
}
```

## 横向误差来源分析

| 误差类型 | 来源 | 量级 | 补偿方法 |
|---------|------|------|---------|
| 稳态误差 | 侧偏角、载荷转移 | 5-20cm | 前馈补偿（曲率） |
| 动态误差 | 延迟、轮胎滑移 | 10-30cm | MPC 预测补偿 |
| 扰动误差 | 路面不平、侧风 | 5-15cm | 鲁棒控制 / 增益调度 |
| 参考线误差 | 地图偏差 | 10-50cm | 定位 + 地图更新 |

## 稳定性边界

**相位裕度**：> 30°
**增益裕度**：> 6dB
**横摆阻尼比**：0.3 - 0.8

**危险信号**：
- 横向误差持续增大（发散）
- 舵角高频震荡（控制饱和或延迟过大）
- 横向加速度 > 0.4g（轮胎侧偏极限）
