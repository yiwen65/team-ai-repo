# 纵向控制参考

## 算法对比

| 算法 | 原理 | 优势 | 劣势 |
|------|------|------|------|
| PID | 误差反馈 | 简单、易调 | 超调、延迟敏感 |
| MPC | 预测优化 | 多约束、预见性 | 计算量大 |
| ACC | 距离控制 | 安全跟车 | 保守、效率低 |
| 滑模控制 | 鲁棒非线性 | 抗干扰 | 抖振 |

## 纵向 MPC 参数

```python
long_mpc_params = {
    "N": 30,
    "dt": 0.1,
    "Q": [0.0, 1.0, 0.0],  # [位置误差, 速度误差, 加速度]
    "R": [0.1, 0.01],     # [jerk, 油门/刹车变化]
    "constraints": {
        "v_max": 33.3,      # 120 km/h
        "a_max": 2.5,       # m/s²
        "a_min": -4.0,      # m/s² (紧急制动)
        "jerk_max": 2.5,    # m/s³
        "jerk_min": -2.5
    }
}
```

## 舒适性标准（ISO 2631）

| 指标 | 舒适 | 轻微不适 | 严重不适 |
|------|------|---------|---------|
| 纵向加速度 | < 1.5 m/s² | 1.5-2.5 | > 2.5 |
| 纵向 jerk | < 2.0 m/s³ | 2.0-3.0 | > 3.0 |
| 横向加速度 | < 1.0 m/s² | 1.0-2.0 | > 2.0 |
| 横向 jerk | < 1.0 m/s³ | 1.0-1.5 | > 1.5 |

## AEB 触发逻辑

**TTC（Time To Collision）计算**：
```
TTC = distance / relative_speed
```

**分级响应**：
| TTC | 响应 |
|-----|------|
| > 3.0s | 预警（提示音） |
| 2.0-3.0s | 部分制动（30%） |
| 1.0-2.0s | 全力制动（100%） |
| < 1.0s | 紧急制动 + 安全带预紧 |

**误触发排查**：
1. 传感器虚警（井盖、金属板）
2. 弯道场景（前方车辆在本车道但路径不冲突）
3. 低矮目标（小动物、纸袋）
