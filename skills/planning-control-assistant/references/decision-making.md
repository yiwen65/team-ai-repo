# 决策逻辑参考

## 状态机设计

典型自动驾驶状态机：

```
[OFF] → [INIT] → [READY] → [DRIVE] → [STOP] → [OFF]
                ↘ [FOLLOW] ↗
                ↘ [OVERTAKE] ↗
                ↘ [PARKING] → [PARKED]
                ↘ [EMERGENCY] → [PULLOVER]
```

## 场景识别与策略

| 场景 | 识别条件 | 策略 |
|------|---------|------|
| 无保护左转 | 路口 + 无专用左转灯 + 对向来车 | 间隙搜索 + 保守决策 |
| 加塞 | 旁车转向灯 + 横向接近 | 减速让行 / 保持车道 |
| 行人横穿 | 斑马线 + 行人检测 | 停车等待 |
| 施工区域 | 锥桶 + 车道线消失 | 降速 + 借道 |
| 异形路口 | 无规则拓扑 | 保守通过 + 人工接管预警 |
| 拥堵跟车 | 低速 + 近距离 + 长时间 | 平滑跟车 + 防加塞 |

## 交互博弈

**保守策略 vs 激进策略**：
- 保守：优先安全，宁可停车不让
- 激进：优先效率，主动寻找间隙
- 推荐：分场景配置，默认保守，可配置激进模式

**决策冲突处理**：
1. 安全 > 法规 > 舒适 > 效率
2. 当安全与法规冲突（如避让救护车），人工接管预警
3. 多个障碍物时，优先处理威胁最大的（TTC 最小）
