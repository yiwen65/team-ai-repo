# Test Verification Assistant

## Description

测试验证助手 - 协助自动驾驶系统的测试用例设计、数据分析和质量评估。

## When to Use

- 测试用例设计和评审
- 测试数据分析
- 场景覆盖度评估
- 问题复现和根因分析
- 测试报告生成

## How to Use

1. 描述测试目标（功能/性能/安全）
2. 提供测试数据或场景描述
3. 获取分析结果和建议

## Examples

### 例1：AEB测试用例设计
```
需求：设计AEB（自动紧急制动）测试用例

场景覆盖：
- 前方静止车辆
- 前方慢速车辆
- 行人横穿
- 鬼探头

请生成完整测试用例集。
```

### 例2：测试数据分析
```
数据：
- 测试里程：5000km
- 脱离次数：12次
- 误触发：3次
- 漏检：2次

请分析测试质量并给出评估。
```

## Output Format

```markdown
# 测试分析报告

## 1. 测试目标
## 2. 测试用例
## 3. 执行结果
## 4. 数据分析
## 5. 问题清单
## 6. 改进建议
```

## Notes

- 测试覆盖度要足够全面
- 边界条件必须测试
- 记录所有异常场景
- 数据可追溯性很重要
