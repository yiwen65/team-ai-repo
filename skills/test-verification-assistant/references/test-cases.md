# 测试用例参考

## 用例模板

```markdown
### TC-XXX: [场景名称]

**优先级**: P0 / P1 / P2
**所属功能**: [功能模块]
**ODD**: [适用运行域]

**前置条件**:
- [ ] 仿真环境启动 / 实车准备就绪
- [ ] 地图加载完成
- [ ] 传感器校准完成

**测试步骤**:
1. [步骤1]
2. [步骤2]
3. [步骤3]

**预期结果**:
- [ ] 结果1（量化指标）
- [ ] 结果2（安全约束）

**通过标准**:
- 量化指标: [具体数值]
- 安全约束: [不碰撞、不越线]

**失败处理**:
- 记录: rosbag、日志、截图
- 分类: 感知/规划/控制/定位/系统
- 优先级: 阻塞/严重/一般
```

## 优先级定义

| 优先级 | 触发条件 | 示例 |
|--------|---------|------|
| P0 | 安全相关、法规强制、高频场景 | AEB 行人、车道保持 |
| P1 | 功能核心、用户高频使用 | ACC、自动变道 |
| P2 | 边缘场景、低概率、优化类 | 异形障碍物、极端天气 |

## 边界条件设计

**感知边界**：
- 最小检测目标：0.3m x 0.3m（锥桶）
- 最大检测距离：200m（车辆）、50m（行人）
- 极端光照：0.1lux ~ 100,000lux

**规划边界**：
- 最小转弯半径：5.5m（乘用车）
- 最大曲率：0.2 1/m
- 极限加速度：-6 m/s²（紧急制动）

**控制边界**：
- 最大舵角：±25°
- 最大舵角速度：200°/s
- 最大纵向 jerk：5 m/s³

## 用例生成方法

1. **专家经验法**：测试工程师基于经验设计
2. **等价类划分**：将参数空间划分为等价区间
3. **边界值分析**：聚焦边界和极值
4. **组合测试**：Pairwise / n-wise 组合
5. **AI 生成**：基于历史脱离数据自动生成
