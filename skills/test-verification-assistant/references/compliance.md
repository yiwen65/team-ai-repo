# 合规检查参考

## ISO 26262（功能安全）

**ASIL 等级**：
| 功能 | ASIL | 说明 |
|------|------|------|
| AEB | D | 最高安全等级 |
| LKA | D | 最高安全等级 |
| ACC | B | 中等安全等级 |
| 自动泊车 | B | 中等安全等级 |

**测试要求**：
- 故障注入测试：传感器失效、通信中断、CPU 过载
- 故障覆盖率：单点故障覆盖率 > 99%
- 安全机制验证：看门狗、冗余监控、降级策略

## ISO 21448（SOTIF）

**预期功能安全**：
- 识别性能不足场景（感知局限、算法局限）
- 识别误用场景（驾驶员滥用、环境误用）
- 定义验收标准（Acceptance Criteria）

**验证方法**：
| 方法 | 适用 |
|------|------|
| 仿真测试 | 大规模场景覆盖 |
| 场地测试 | 可控场景验证 |
| 开放道路 | 真实环境验证 |
| 影子模式 | 大规模无风险验证 |

## NCAP / C-NCAP 评分

**权重分布（C-NCAP 2024）**：
| 测试项 | 权重 | 说明 |
|--------|------|------|
| AEB 车对车 | 20% | CCRs, CCRm, CCRb |
| AEB 行人 | 20% | CPRA, CPLA, CPNCO |
| AEB 骑车人 | 10% | CBNA, CSFA, CBLA |
| LKA | 15% | LDW + LKA |
| BSD | 10% | 盲区监测 |
| ACC | 15% | 自适应巡航 |
| 其他 | 10% | 速度辅助、灯光等 |

**评分标准**：
- 5星：总分 >= 90%
- 4星：总分 80-89%
- 3星：总分 70-79%

## 合规检查清单

- [ ] 所有 ASIL D 功能通过故障注入测试
- [ ] SOTIF 场景库覆盖 > 10,000 具体场景
- [ ] NCAP 评分 >= 4 星
- [ ] 脱离率 < 0.1 次/100km（开放道路）
- [ ] 误触发率 < 0.01 次/100km
- [ ] 系统可用率 > 99.9%
