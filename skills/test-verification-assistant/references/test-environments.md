# 测试环境参考

## SIL（软件在环）

**平台**：
- ROS2 + Gazebo / Carla / LGSVL
- 感知模型：直接注入检测结果（绕过传感器仿真）
- 用途：算法逻辑验证、回归测试、大规模场景

**Carla 配置要点**：
```python
carla_config = {
    "sync_mode": True,
    "fixed_delta_seconds": 0.05,  # 20 Hz
    "sensor_tick": 0.1,  # 传感器 10 Hz
    "weather": {
        "cloudiness": 30,
        "precipitation": 0,
        "sun_altitude_angle": 70
    }
}
```

## HIL（硬件在环）

**组成**：
- 仿真机（场景 + 车辆动力学）
- 被测 ECU（真实控制器）
- 信号接口（CAN/Ethernet 仿真）

**用途**：
- 控制器验证（真实 ECU 代码）
- 通信测试（CAN 延迟、丢包）
- 硬件兼容性（驱动、资源占用）

## VIL（车辆在环）

**组成**：
- 真实车辆（底盘 + 传感器）
- 场景注入（VR/AR 或封闭场地）
- 安全员 + 紧急制动系统

**用途**：
- 传感器真实响应验证
- 执行器响应验证
- 人机交互验证

## 实车测试

**要求**：
- 封闭场地：完成基础功能验证
- 开放道路：分阶段（简单→复杂）
- 安全冗余：安全员 + 远程监控 + 双系统

**测试规范**：
- 最小测试里程：1000km/版本
- 脱离间隔：> 100km/次（成熟系统）
- 夜间/雨天比例：> 20%
