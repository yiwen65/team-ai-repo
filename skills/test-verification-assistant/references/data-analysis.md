# 数据分析参考

## 脱离（Disengagement）分析

**脱离分类**：
| 类别 | 占比（典型） | 根因 |
|------|------------|------|
| 感知 | 40% | 漏检、误检、类别错分 |
| 规划 | 25% | 无解、轨迹不合理、决策错误 |
| 控制 | 15% | 跟踪误差大、执行器饱和 |
| 定位 | 10% | GPS 漂移、地图匹配失败 |
| 系统 | 10% | 软件崩溃、通信超时、传感器掉线 |

**脱离率计算**：
```
脱离率 = 脱离次数 / 测试总里程 (次/100km)
接管率 = 安全员接管次数 / 测试总里程
系统可用率 = (总时间 - 不可用时间) / 总时间
```

**趋势分析**：
- 版本对比：脱离率是否下降
- 场景细分：哪些场景脱离最多
- 时间分布：是否集中在特定时间段（光照变化）

## 误触发 / 漏检分析

**误触发分类**：
| 类型 | 典型场景 | 解决方案 |
|------|---------|---------|
| AEB 误触发 | 井盖、金属板、低矮障碍物 | 提高分类精度、增加高度滤波 |
| 车道偏离误报 | 老旧道路、施工标线 | 置信度阈值 + 地图校验 |
| 幽灵刹车 | 桥梁接缝、阴影 | 时序滤波 + 多帧确认 |

**漏检根因**：
- 小目标（< 32x32px）：分辨率不足
- 遮挡（> 50%）：特征不完整
- 相似类别：行人 vs 骑车人
- 极端姿态：侧翻车辆、倒地行人

## 性能指标

| 指标 | 定义 | 目标值 |
|------|------|--------|
| MPD（Miles Per Disengagement） | 测试里程 / 脱离次数 | > 1000 英里 |
| TTC 准确率 | 碰撞时间预测误差 | < 0.5s |
| 规划耗时 | 轨迹生成时间 | < 100ms |
| 控制跟踪误差 | 横向 RMS | < 0.2m |
| 系统延迟 | 感知到控制输出 | < 200ms |
